Web Technologies

HTML

HTML, which stands for HyperText Markup Language, is the standard code used to structure and display content on the internet. It acts as the digital skeleton for every webpage, using a system of tags to organize elements like headings , paragraphs, links, and images. By defining these structural components

CSS

SS, which stands for Cascading Style Sheets, is a fundamental coding language used to define the visual presentation and layout of web pages written in HTML. While HTML provides the basic structure of a website, CSS allows developers to apply colors, fonts, spacing, and responsive designs that adapt to different screen sizes

JavaScript

JavaScript (JS) is a high-level programming language that brings interactivity and dynamic behavior to web pages. Alongside HTML for structure and CSS for style, JS powers features like pop-up menus, animated graphics, and real-time content updates without reloading the page. It runs directly in web browsers on the client side
